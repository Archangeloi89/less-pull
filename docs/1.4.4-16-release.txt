Less Pull 1.4.4 — build 16

The version number stays 1.4.4 for good; the build number is what changes. Releases are tagged v1.4.4-<build> and carry a lesspull-update.json file that says which macOS versions the build is made for.

What is new, from the app improvements approved on 8 October 2026:
- A warm icon set: app icon, browser extension icons (a dark tile that stays visible on light and dark toolbars) and menu-bar images.
- Plain language everywhere: status lines, tooltips, alerts, Diagnostics and a small scrollable Help window. One vocabulary in the app and the extension: Use default for an inherited value, exception for a rule.
- First launch: Settings opens once with a short welcome above the real Grayscale and Launch at login controls.
- A shorter menu: one status line, Grayscale, the Extra Warmth slider, Night Shift (with its timed off and following in a submenu), Pause Less Pull, Exception for the current app (with its own Default / On / Off choices and warmth slider), Settings and Quit.
- Settings with sections: General, Apps (the exceptions list inline, with app icons, running apps in Add app…, and Default / On / Off segments), Websites (extension status, install button, the saved website rules with Remove) and About.
- The warmth slider track shows the real neutral to amber to red ramp.
- The menu-bar icon shows state: its left half fills while grayscale is showing, its right half takes the warmth color, a pause mark shows while paused, and a small dot shows when a newer build is available.
- The extension popup shows what a default resolves to, e.g. Use default (On); Save exception is the primary button; the back button only appears after choosing a saved rule. Extension 0.2.0.
- Every exception, for an app or a website, has “Use this exception”: off keeps the settings without applying them, and any change away from default switches it on again.
- Pause Less Pull for 15 minutes, 1 hour or until resumed: the plain display, rules ignored, settings kept, survives a relaunch.
- Peek in color: hold a shortcut recorded in Settings → Shortcuts to see the plain display; press it twice quickly to keep the plain display, once more to return; choose there what it turns off (Grayscale, Extra Warmth, Night Shift). Suggest picks a shortcut that is free of macOS shortcuts. No Accessibility permission needed.
- A Toggle Grayscale shortcut, Grayscale off for 1 hour, 4 hours or until Night Shift changes (menu and Settings), and a choice of what clicking the menu-bar icon does: by default a click opens the menu and a right-click toggles Grayscale; Settings → Shortcuts can swap the two.
- Updates, phase 1: once a day one request asks GitHub for the latest release; builds made for another macOS version are not offered; installing stays manual until the app is signed and notarized.
- More browsers: the same extension code ships with a Firefox manifest (Mozilla native-host registration), accepts Opera and Edge, and runs in Safari through a companion app built with Xcode (Less Pull for Safari.app inside the app; its handler forwards messages to the Less Pull socket). Several browsers can use the extension at once. The extension has no popup or toolbar button any more (0.4.0): it only connects the browser, and website exceptions are set from the menu-bar menu, like app exceptions, for the whole domain or one exact page.
- A thank-you window after 30 days of use, once, with the author's links. Later asks again in 90 days.
- Settings uses the standard window material, so it follows the macOS transparency setting.
- The executable is now LessPull and the bundle identifier is com.jiriarion.lesspull. The first launch copies settings from the old local.nightshiftfilters.app domain once; Launch at login may need to be checked again.

Behaviour that did not change: grayscale stays the user's choice day and night; following controls warmth only; half-second fades (immediate under Reduce Motion); the build 15 display-recovery fix; rule precedence global, app, domain, exact URL, resolved per effect; private tabs excluded; no webpage injection; no network service, analytics or third-party runtime dependencies.

Verified: all ten suites pass (policy, matrix, pause/DST, 576 combined controller cases plus the new Pause Less Pull, Peek in color and update-check cases, fades, website rules with inherited-value resolution and Firefox contexts, menu geometry, the extension worker with the Firefox manifest and label checks, and display recovery). Verified live on this Mac with an isolated test copy: the welcome card, every Settings tab including scrolling with twelve app rules, segment and checkbox actions saving, website-rule Remove, the ramp slider, the menu-bar icon states (grayscale, color, warmth, update dot), Pause Less Pull from the menu, the Peek shortcut (recorded and held), the manual update check against the still-private repository, the thank-you window, and the native host accepting Firefox-style arguments. Verified live since: Firefox, Safari and Opera connect to the bridge on this Mac. Not verified: a clean Chrome installation, Edge, other macOS versions, extended sleep and display reconnect.

The privacy promise changed in one place: the app contacts GitHub once a day to look for a newer build, sends nothing else, and the check can be turned off in Settings → About. See docs/PRIVACY.md.

Apple silicon; macOS 13+ build target, macOS 27 tested. Ad-hoc signed, not notarized. Private Apple interfaces may change.
