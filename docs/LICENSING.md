# Licensing

Less Pull is free to use and source-available. It is not open source. There are two licenses:

- The [app license](../LICENSE-APP.txt) covers using and sharing the unmodified app and extension.
- The [source license](../LICENSE-SOURCE.txt) covers the code, tests, scripts and original repository assets.

The table is a summary. The license texts are what count.

| You want to | Allowed? |
| :-- | :-- |
| Use the official app or extension, personally or at work | Yes, free |
| Deploy the unmodified app to employees | Yes, free |
| Share the complete, unmodified app free of charge | Yes, with the license and copyright notices |
| Read the source, or build it unchanged for your own use | Yes |
| Modify the code and share it for noncommercial purposes | Yes, with the notices and clear labels on what you changed |
| Adapt the code into a commercial product, or sell a derivative | Only with the author's written permission |
| Sell or commercially bundle the original app | Only with the author's written permission |

The app license also covers running the JavaScript inside the official extension. It does not grant the right to modify it commercially.
