Build note: build.sh includes the Safari companion app (Less Pull for Safari.app, generated by safari-web-extension-converter and built ad hoc) when /Applications/Xcode.app exists; set LESS_PULL_SKIP_SAFARI=1 to skip it.
Other launch options for testing: --settings opens Settings; --welcome opens the first-launch window again; --regular keeps a Dock icon so UI automation can reach the app; --menu-test mirrors the status menu into the app menu; --thanks shows the thank-you card in Settings at once; --hands-off makes the copy leave the displays and Night Shift alone (it still shows every state), so a test copy can run beside the installed app without fighting it.
To test without touching saved preferences, copy the built app, change CFBundleIdentifier to a test value (for example local.nightshiftfilters.test), remove LSUIElement if --regular is wanted, re-sign ad hoc, and quit the installed copy first.
